# Medical Diagnosis Demo Website

## Project Description
This project is a simple medical diagnosis support system created for educational purposes.
The frontend is developed using HTML, CSS, and JavaScript.
The backend diagnosis logic is implemented using C++ with Object-Oriented Programming (OOP).

## Features
- Simple medical diagnosis simulation
- User-friendly web interface
- C++ OOP-based diagnosis logic
- Frontend hosted on GitHub Pages

## Technologies Used
- HTML
- CSS
- JavaScript
- C++

## Project Structure
- Frontend: Website interface using HTML, CSS, and JS
- Backend: C++ program containing diagnosis logic

## Note
Due to GitHub Pages limitations, the C++ backend is implemented as a standalone module.
The frontend demonstrates backend interaction through simulation.

## Disclaimer
This project is for educational purposes only and does not provide real medical advice.
